# SENSA4D

Sebuah website statis interaktif yang dirancang dengan performa cepat dan tampilan modern. Proyek ini dibangun menggunakan teknologi web standar untuk memberikan pengalaman pengguna yang optimal.

🚀 **Live Demo:** [Kunjungi Website di Sini](https://sensa-4d.github.io/mainsensa/)

---

## ✨ Fitur Utama
* **Desain Responsif:** Tampilan web menyesuaikan dengan sempurna di perangkat mobile, tablet, maupun desktop.
* **Performa Cepat:** Karena menggunakan file statis, pemuatan halaman menjadi sangat ringan dan instan.
* **Navigasi Intuitif:** Antarmuka pengguna yang bersih dan mudah dipahami oleh pengunjung.

## 🛠️ Teknologi yang Digunakan
* **HTML5** – Struktur semantik halaman web.
* **CSS3** – Penataan gaya layout dan estetika visual.
* **JavaScript** – Interaktivitas dan fungsionalitas dinamis pada halaman.

## 📁 Struktur Repositori
* `AMP/` – Folder berisi aset atau modul pelengkap website.
* `README.md` – Dokumentasi utama proyek.
